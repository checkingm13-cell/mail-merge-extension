# 03 - Email Template Matrix (232 Combinations)

## Overview

The extension seeds **232 unique template combinations** directly into IndexedDB (`GmailMailMergeDB` v5). This matrix is created by pairing **8 template families** (4 Journals × 2 Formats) across **29 predefined subjects**.

---

## The 8 Template Families

Formatted in **22px Verdana** (`font-family: Verdana, Geneva, sans-serif; font-size: 22px; line-height: 115%`) with salutation `Dear [FNAME]`, academic hook copy, hyperlinked call-to-action button, closing statement, and dedicated OptOut link.
